# Midnight copy style

Use sentence case for buttons, card headings, field labels, alert actions, and status labels.

Keep capitals for:

- Midnight and screen names when the copy points to a destination: Today, Plan, Progress, Awards, and Settings
- named features and metrics: Discipline Rating, Day Score, Recovery Day, Focus Sprint, Player Card, and Midnight Evaluation
- rank names, award names, and named midnight outcomes
- abbreviations such as DR and XP

Use lowercase for generic nouns, including `award`, `awards`, `quest`, `rank`, `archive`, and `profile`.

End full explanatory sentences and award descriptions with punctuation. Leave short labels and button text without terminal punctuation. Use the single ellipsis character (`…`) for progress labels and truncated prompts.
